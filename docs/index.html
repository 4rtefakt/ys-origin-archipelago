Ys Origin × Archipelago

A randomizer for Ys Origin that joins Archipelago multiworlds. The whole of Darm Tower is shuffled, you play as Yunica, Hugo or Toal, and everything runs inside the game through one small file you drop in its folder.

Setup, step by step

About ten minutes, once. You need Ys Origin on Steam (version 1.1.1.0, the current build) and nothing else to start.

  1. Install Archipelago

    Download the installer from archipelago.gg and run it. You need it to generate or host a game; to join a friend's game you still install it.

  2. Get the two files

    Both come from the latest release of this project.

    Download ys_origin.apworld Download dinput8.dll

  3. Add Ys Origin to Archipelago

    Copy ys_origin.apworld into the custom_worlds folder inside your Archipelago install. Double-clicking the file does the same thing.

  4. Make your settings file

    Use the builder below: pick your character and options, download the file, and put it in Archipelago's Players folder. Everyone in the multiworld brings one settings file for their own game.

  5. Generate and host

    Open the Archipelago Launcher and choose Generate. Then host the result from the Launcher, or upload it at archipelago.gg/uploads. You get a room address such as archipelago.gg:12345.

    Joining someone else's game? Skip this step: send them your settings file and the .apworld, and they give you the address.

  6. Install the mod in the game

    Copy dinput8.dll into the Ys Origin folder, the one that contains yso_win.exe. Usually:

    C:\Program Files (x86)\Steam\steamapps\common\Ys Origin\

    To uninstall later, delete that file.

  7. Connect from the title screen

    Start the game. The title screen has a new Archipelago entry above New Game: press F8 to open it and fill in:

    • Server, for example archipelago.gg
    • Port, your room's port
    • Slot, the name in your settings file
    • Password, blank unless the room has one

    Move with Tab or the arrow keys, then press Enter. The status line tells you the result.

  8. Play

    Start a New Game or load your save. An Archipelago overlay sits in the top right with your connection, your room and your items. Open chests as usual: you get the randomized item, and what other players find for you arrives by itself. Insert hides or shows the overlay.

If something goes wrong

    
The most common problems and what fixes them.

    

      
No overlay in the game
Press Insert. If nothing shows, the mod did not load: check that dinput8.dll is in the same folder as yso_win.exe.

      
It will not connect
The server, the port and the slot must match the room exactly, and the slot is the name in your settings file, capitals included.

      
The game does not start, or crashes at once
The mod is built for the current Steam build of Ys Origin, version 1.1.1.0. Check your game is up to date and that the dll comes from the latest release.

      
Starting gear is missing
Do not run another Archipelago client for Ys Origin next to the mod. The mod is the client, and two of them conflict.

      
Reporting a bug
The mod writes a log to %TEMP%\yso_ap_mod.log. It is safe to share: your Windows user name, the room's port and the password are left out. Attach it to an issue on GitHub.
